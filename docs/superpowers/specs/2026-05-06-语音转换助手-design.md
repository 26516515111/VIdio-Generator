# 语音转换助手设计文档

## 1. 项目概述

### 1.1 项目目标
设计一个语音转换助手软件，前端用户输入文字或图片，后端处理后提取文字，根据用户描述（心情等）经过大模型加工后送入TTS大模型，最终返回一段文字和相对应的语音。

### 1.2 核心功能
1. **文字输入**：用户直接输入文字
2. **图片输入**：用户上传图片，系统提取文字和场景
3. **场景演绎**：用户输入场景描述或上传场景图片，系统自动推断情绪和加工方式
4. **大模型加工**：对提取的文字进行文本润色、情绪增强、内容扩展、风格转换等加工
5. **语音合成**：将加工后的文字转换为语音
6. **结果返回**：先返回处理后的文字，再返回生成的语音

## 2. 架构设计

### 2.1 整体架构
单体应用，前后端融合，打包成单一可执行文件（.exe）

### 2.2 技术栈

#### 前端
- **框架**：React 18 + TypeScript
- **状态管理**：Redux Toolkit
- **UI组件库**：Ant Design
- **构建工具**：Vite

#### 后端
- **框架**：Python 3.11 + FastAPI
- **数据库**：SQLite（本地数据库，无需单独安装）
- **ORM**：SQLAlchemy 2.0
- **认证**：JWT + OAuth2

#### 外部服务（可切换，默认使用小米）
- **OCR**：小米MiMo V2.5多模态能力（图片文字提取和场景识别）
  - 可选：其他OCR服务（如百度OCR、腾讯OCR等）
- **大模型加工**：小米MiMo V2.5 Pro（文本润色、情绪增强、内容扩展、风格转换）
  - 可选：其他大语言模型（如OpenAI GPT、Claude等）
- **TTS**：小米MiMo TTS（文本转语音）
  - 可选：其他TTS服务（如阿里云TTS、腾讯云TTS等）

### 2.3 部署架构
- **打包**：使用PyInstaller将Python后端打包成.exe文件
- **前端**：构建为静态文件，通过PyInstaller的`--add-data`选项嵌入到.exe文件中
- **数据库**：SQLite数据库文件存储在本地
- **运行**：用户下载.exe文件，双击运行，自动启动本地Web服务器
- **访问**：用户通过浏览器访问本地Web应用（默认地址：http://localhost:8000）

## 3. 组件设计

### 3.1 前端组件

#### 3.1.1 输入组件
- **文字输入框**：用户直接输入文字
- **图片上传组件**：用户上传图片（支持常见图片格式）

#### 3.1.2 场景演绎组件
- **场景描述输入**：用户输入场景描述文字
- **场景图片上传**：用户上传场景图片
- **情绪推断**：系统自动推断情绪（开心、悲伤、愤怒、平静等）
- **加工方式选择**：系统推荐加工方式，用户可调整

#### 3.1.3 结果展示组件
- **文字展示**：显示处理后的文字
- **语音播放器**：播放生成的语音
- **历史记录**：查看历史处理记录

#### 3.1.4 用户认证组件
- **登录**：用户登录
- **注册**：用户注册
- **个人中心**：用户个人资料管理

### 3.2 后端组件

#### 3.2.1 用户服务
- **用户认证**：JWT token生成和验证
- **用户授权**：基于角色的访问控制
- **个人资料管理**：用户信息的增删改查
- **API密钥管理**：用户可以配置和管理自己的API密钥
- **模型选择**：用户可以选择不同的大语言模型、OCR和TTS服务提供商

#### 3.2.2 OCR服务
- **文字提取**：调用小米MiMo V2.5多模态能力提取图片中的文字
- **场景识别**：识别图片中的场景（室内、室外、人物、物体等）

#### 3.2.3 大模型加工服务
- **文本润色**：优化文字表达，使其更流畅自然
- **情绪增强**：根据情绪调整文字表达方式
- **内容扩展**：基于输入内容生成更丰富的描述
- **风格转换**：转换文字风格（正式/口语化/文学化等）

#### 3.2.4 TTS服务
- **语音合成**：调用小米MiMo TTS将文字转换为语音
- **音色选择**：支持多种音色选择
- **情绪控制**：根据情绪调整语音语调

#### 3.2.5 数据存储服务
- **用户数据管理**：存储用户信息
- **历史记录管理**：存储处理历史
- **文件存储**：存储上传的图片和生成的语音文件

## 4. 数据流设计

### 4.1 用户输入流程
1. 用户输入文字或上传图片
2. 如果上传图片，调用OCR服务提取文字和场景
3. 用户输入场景描述（可选）
4. 系统自动推断情绪和加工方式
5. 用户确认或调整

### 4.2 后端处理流程
1. 接收用户输入
2. 调用OCR服务（如果需要）
3. 调用大模型加工服务
4. 调用TTS服务生成语音
5. 返回处理后的文字和语音

### 4.3 数据存储流程
1. 存储用户输入（文字/图片）
2. 存储处理后的文字
3. 存储生成的语音文件
4. 存储用户历史记录

## 5. 错误处理设计

### 5.1 前端错误处理
1. **输入验证**：检查文字长度、图片格式和大小

## 9. 配置需求

### 9.1 API密钥配置
用户可以配置以下API密钥（默认使用小米服务）：
- **小米服务**（默认）：
  - 小米MiMo V2.5多模态能力API密钥
  - 小米MiMo V2.5 Pro API密钥
  - 小米MiMo TTS API密钥
- **其他服务**（可选）：
  - 其他OCR服务API密钥
  - 其他大语言模型API密钥
  - 其他TTS服务API密钥

**注意**：如果小米提供统一的API密钥，用户只需配置一个密钥即可访问所有小米服务。

### 9.2 系统要求
- **操作系统**：Windows 10/11
- **内存**：至少4GB RAM
- **存储空间**：至少1GB可用空间
- **网络**：需要互联网连接（用于调用外部API）

## 10. 安全考虑

### 10.1 数据安全
- 用户密码使用bcrypt加密存储
- API密钥加密存储
- 敏感数据不记录日志

### 10.2 网络安全
- 使用HTTPS（本地开发可使用HTTP）
- API请求添加认证token
- 输入验证防止注入攻击

### 10.3 文件安全
- 上传文件类型验证
- 文件大小限制
- 文件存储路径安全
